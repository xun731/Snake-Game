# 貪食蛇（精選版）

高一資訊課專題作品｜Visual Basic｜2022年6月

## 專案簡介

學習 Visual Basic 將近一學期後，嘗試以課堂所學製作一款具備
完整遊戲系統的貪食蛇。沒有老師提供的素材、沒有分享螢幕指引，
從零開始構思、踩坑、除錯，最後做出來的。

## 遊戲功能

- **開始頁面**：互動式按鈕（滑鼠移入/離開觸發效果）、遊戲說明視窗
- **遊戲設定**：可調整蛇的移動速度、背景音量、蛇身顏色
- **遊戲模式**：普通版、毒蘋果模式（吃到綠蘋果扣分）、挑戰版（速度隨身體增長）
- **計分系統**：即時分數 + 最高分紀錄（解決 int 型態比較的 Bug）
- **開始倒數**：3秒倒數計時動畫
- **暫停機制**：暫停鍵 + 對應音效
- **結束畫面**：重新開始（保留最高分）/ 回首頁（清除紀錄）
- **背景音樂與音效**：各頁面搭配不同音效，含吃食物、死亡、按鈕音效

## 開發過程遇到的挑戰

- `Label` 最高分卡在 9 → 改為 `int` 型態比較解決
- `Hide()` 突然失效 → 改用 `Application.OpenForms()` 宣告已開啟的 Form
- 多視窗同步顯示 → `Me.Hide()` + `Show()` 控制頁面切換
- `PictureBox` 旋轉方向 → `RotateFlip()` 各參數測試
- 沒有 `Sleep` → 使用 `System.Threading.Thread.Sleep(300)` 讓音效播完再結束

## 使用技術

- Visual Basic（Windows Forms）
- 多表單（Multi-Form）架構
- Timer 元件控制遊戲節奏
- Shared 變數跨 Form 共用資料
- MouseMove / MouseLeave 事件製作互動按鈕
